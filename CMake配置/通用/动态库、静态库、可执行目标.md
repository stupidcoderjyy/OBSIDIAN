##### 1. 设置目标名称
`set(TARGET target)`
##### 2. 添加目标（必须）
静态库：`add_library(${TARGET} STATIC ...)`
动态库：`add_library(${TARGET} ...)`
可执行目标：`add_executable(${TARGET} ...)`
##### 3. `target_include_directories`（必须）
用法：
```cmake
target_include_directories(
	<target>
    <PRIVATE | PUBLIC | INTERFACE> <item>...
    [<PRIVATE | PUBLIC | INTERFACE> <item>...]...
)
```
`PRIVATE` - 包含目录只能被当前目标使用，不能被依赖该目标的其他目标使用
`PUBLIC` - 包含目录可以被当前目标和依赖该目标的其他目标使用
`INTERFACE` - 包含目录只能被依赖该目标的其他目标使用，常用于纯头文件库
`<item>` - 包含目录
##### 4. `target_link_libraries`（必须）
用法：
```cmake
target_link_libraries(
    <target>
    [<PRIVATE | PUBLIC | INTERFACE> <item>...]...
)
```
`PRIVATE` - 链接项只用于当前目标。==🟣避免对静态库使用==
`PUBLIC` - 链接项用于当前目标，且传播到依赖该目标的其他目标
`INTERFACE` -  链接项只传播到依赖该目标的其他目标
`<item>` - cmake目标、带命名空间的导入目标、库文件路径
